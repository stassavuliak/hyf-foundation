Application Components
1. User
Interacts with the application to create, view, edit and delete recipes.

2. Frontend
Displays the user interface, handles user interactions and sends HTTP requests to the backend.

3. Backend
Processes requests, validates data, handles business logic and communicates with the database.

4. Database
Stores recipe information permanently, including titles, ingredients and instructions.

Recipe data is stored in a database, such as PostgreSQL.

The frontend communicates with the backend through a REST API using HTTP requests and responses. JSON is used as the data format.
